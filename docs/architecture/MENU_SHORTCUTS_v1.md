# 앙개봇 2.0 단축 메뉴·콘텐츠 경계 설계 (v1)

## 목표

기존 카카오톡 알림 기반 Android Bridge, 인증된 Python FastAPI, 읽기 명령, 관심종목, AI, 배터리 표시, SQLite 작업·이벤트 로그, 5분 숫자 선택을 모두 보존하면서 콘텐츠별 단축 메뉴 진입을 제공한다.

## 호출어 (정확히 일치하는 메시지만 인식)

| 메시지 | 동작 | 구현 단계 |
|---|---|---|
| `앙`, `앙개야`, `앙개야 메뉴` | 메인 메뉴 | 구현 |
| `주` | 기존 주식 메뉴 | 기존 구현 유지 |
| `주 분 삼성전자`, `주 목록` | 기존 주식 분석·관심목록 단축어 | 기존 구현 유지 |
| `민` | 배드민턴 | 카테고리 메뉴 구현·세부 기능 준비 중 |
| `요` | 요리 | 카테고리 메뉴 구현·세부 기능 준비 중 |
| `여` | 여행 | 카테고리 메뉴 구현·세부 기능 준비 중 |
| `종` | 종친 | 카테고리 메뉴 구현·세부 기능 준비 중 |
| `영` | 영어 | 카테고리 메뉴 구현·세부 기능 준비 중 |
| `상` | 기존 Android 로컬 상태 | 기존 로컬 명령 유지 |
| `도` | 기존 Android 로컬 도움말 | 기존 로컬 명령 유지 |

단축 콘텐츠는 메시지 전체가 한 글자인 경우에만 인식한다. 사용자 지정 호출어가 정확히 일치하면 기존 호출어 처리 우선이다. `요리`, `영어`, `앙상블` 같은 일반 메시지를 단축어로 오해하지 않는다.

## 숫자 이동

- `1`~`10`: 현재 메뉴에서 번호 선택 (최종 엔진은 고정 메뉴 정의 및 정식 명령에만 연결)
- `0`: 한 단계 이전으로 이동. 최상위 홈에서 `0`은 홈 재표시
- `00`: 즉시 홈으로 이동
- 선택 가능 시간: 5분, 방·발신자별 격리, 최대 200 세션
- Android에서 숫자 명령은 먼저 허용 방·발신자 확인, 인증된 Python 응답에서 `menu_active=true`가 확인되고 카카오톡 `RemoteInput` 회신이 요청되었을 때만 활성화
- 활성 세션이 없거나 다른 사람의 방/발신자라면 숫자 선택을 실행하지 않음
- 서버 재시작 시 메뉴는 소멸. 사용자 데이터는 삭제하지 않음

## 홈 구조

1. 주식 — 기존 주식 메뉴로 연결
2. 배드민턴 — 강좌·기술 / 영상 라이브러리 / 자세 분석 / 훈련 기록
3. 요리 — 요리 추천 / 레시피 찾기 / 보유 재료 활용 / 장보기
4. 여행 — 여행지 추천 / 여행 일정 / 이동 경로 / 맛집·숙소
5. 종친 — 종친회 안내 / 행사 일정 / 계보·자료 / 회비 안내
6. 영어 — 생활 영어 / 회화 / 어휘 / 복습

현재 미개발 하위 콘텐츠는 '개발 예정' 텍스트와 같은 메뉴를 반환한다. 계보·회비 등 개인정보가 필요한 콘텐츠의 실제 조회, 변경·등록·삭제, 원격 PC 제어, 주식 주문, 자동 발신은 구현하지 않는다.

## 소스 경계

- `CommandParser.kt`: 정확한 단축 호출어를 허용된 명령으로만 변환
- `MenuSelectionGate.kt`: 기존 5분/스코프 TTL과 숫자 파싱; 공통 `메뉴 선택`으로 연결
- `KakaoNotificationListener.kt`: 기존 허용목록·SQLite dedup·로그/RemoteInput; `menu_active`만 사용
- `PythonBridgeClient.kt`: 기존 인증 토큰과 `/v1/commands` HTTP JSON 프로토콜 유지
- `selection_menu.py`: 주식 메뉴·시세표 선택 상태를 재사용하는 통합 홈 및 미구현 콘텐츠 표시
- `main.py`: 같은 jobs/events 저장 및 request_id 중복 방지 경로로 메뉴 실행
- `market.py`, `watchlists.py`, `history.py`: 기존 구현 유지

## 이후 아키텍처 작업

콘텐츠별 실제 기능을 개발할 때에는 고유한 **menu_id**와 **action_id**로 등록하고 Python Core 공통 메뉴 레지스트리에 연결한다. 현재 단계에서는 소규모 정적 메뉴이며, 콘텐츠 파일/데이터베이스/관리자 권한을 새로 생성하지 않는다. 각 콘텐츠는 주식, 배드민턴, 요리, 여행, 종친, 영어 단위의 독립 테스트 및 문서와 함께 순차적으로 분리한다.

## 배포·검증 규칙

신규 브랜치 `feature/global-shortcut-menus-20261106`에서 Python 전체 회귀, Android 메뉴 테스트 및 디버그 APK 빌드, 배포 스크립트 검사를 GitHub Actions로 진행한다. `main` 병합은 메인 채팅에서 사용자 승인 후 진행한다. 단축 호출어를 실제 카카오톡에서 수신하려면 새로운 Android APK 설치가 필요하며, Core만 업데이트해서는 한 글자 단축어가 작동하지 않는다.

## 보안 주의

카카오톡 알림의 방 이름 및 발신자 이름은 강력한 신원 인증 수단이 아니므로 종친회 회원·계보 개인정보, 회비 처리, 서버·GitHub·소스 제어 명령은 일반 채팅 메뉴에 노출하지 않는다. 해당 기능들은 별도의 인증·인가 설계 완료 후 개발한다.
