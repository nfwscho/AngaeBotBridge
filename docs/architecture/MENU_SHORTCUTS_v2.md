# 앙개봇 2.0 메뉴 설계 v2 — 앙패스(AngaPass)

## 변경 목표

- 기존 브리지·Core의 카카오톡 허용 방/발신자, 로그, .env, SQLite jobs/events, 사용자 설정, AI OFF, stock/market/history, 배터리와 메뉴 TTL 유지
- 6번 영어 대신 6번 날씨, 7번 설정·운영 신규 메뉴 추가
- 단축어 `날` → 날씨, `설` → 설정·운영
- `영` 단축 호출은 제거하되 기존 기타 장문 명령·주식 단축어는 계속 사용
- 한 번의 메시지로 메뉴 경로를 이동하는 **앙패스(AngaPass)** 도입

## 앙패스(AngaPass)

정확한 숫자 메뉴 경로를 공백으로 연결하여 최대 5단계까지 이동한다.

| 메시지 | 이동 |
| --- | --- |
| `주 2` | 주식 → 메모리7 시세 조회 |
| `주 2 2` | 주식 → 메모리7 시세 목록의 2번 종목 분석 |
| `앙 1 2 2` | 홈 → 주식 → 메모리7 → 2번 분석 |
| `주 6 2` | 주식 → 종목별 분석 → 2번 하이닉스 분석 |
| `설 2` | 설정·운영 → 배포 버전·커밋 |
| `설 3` | 설정·운영 → 현재 방/발신자 최근 명령 로그 |
| `날 1` | 날씨 → 오늘 날씨 (실제 날씨 데이터 연동은 개발 예정) |

일반 `0`은 이전 메뉴, `00`은 홈으로 돌아가는 기존 동작을 유지한다.
메뉴 점프는 1개의 인증된 FastAPI 명령으로 전달되어 jobs/events 로그에 1회 기록되며, 중간 시세 목록을 네트워크로 조회하거나 카카오톡으로 여러 번 전송하지 않는다. 최종 시세 또는 분석 명령만 기존 모듈에서 실행한다. 중간 관심그룹·관심목록 선택은 동일 방·발신자 보관 데이터를 조회하고 번호 1~10의 실제 표시 순서를 사용한다. 임의 텍스트/부작용 명령/5단계 초과는 제한한다.

## 읽기 전용 설정·운영

```text
⚙️ 설정·운영 메뉴
1. 서버·서비스 상태
2. 배포 버전·커밋
3. 최근 실행 로그
4. 설정 현황 (읽기 전용)
5. 명령 통계
6. 최근 오류
※ 조회 전용 · 설정 변경은 관리자 화면에서만
```

- 서버 상태: 기존 service_status/runit 상세상태, SSH, Core 가동시간 재사용
- 배포: Core 런타임 버전, 실제 배포 후 기록한 Git SHA 앞 12자, 브랜치, 시각, 동일 실행에서 Android APK 설치 여부를 조회; 기록이 없다면 "미기록" 표시
- 로그: Python Core SQLite jobs의 동일 room/sender 최근 6건 결과 및 시각만 표시. 로그의 argument/result, AI 질문 원문, 토큰, Android 로컬 SQLite 로그는 일반 카카오톡에 노출하지 않는다. Android 상세 로그는 기존 앱 관리 화면 이용
- 설정: AI ON/OFF 요약과 5분 세션, 사용자별 메뉴 범위 등 비밀이 아닌 상태만 표시
- 통계·최근오류: 기존 scoped ops 함수 재사용
- 이 단계의 설정·운영 메뉴는 **읽기 전용**이다. 서버 서비스 변경, GitHub 변경, 토큰·환경변수 수정, 로그 삭제 등 관리자 권한 기능은 포함하지 않는다.

## 신뢰 및 보호

- 메뉴 번호·한 글자 호출어는 Android 허용방/허용발신자 확인 이후만 처리한다.
- 동일 원문 알림은 기존 SHA-256 request_id 및 SQLite dedup으로 재실행 방지한다.
- 숫자 선택은 정상 Core의 menu_active를 받았고 RemoteInput 답장을 요청한 경우에만 5분 동안 허용된다.
- 앙패스는 숫자 전체 경로를 입력한 단일 명시적 명령이다. 5분 전 메뉴 세션이 없어도 실행 가능하되 Core API 토큰 인증과 방·발신자 확인을 통과해야 한다.
- 날씨 하위 항목은 현재 플레이스홀더이며 허위 기온/예보를 표시하지 않는다.
- Core API 버전 0.6.0, Android Bridge v0.4.8(versionCode 12). 기존 주식·AI·배터리·설정·Android 앱 데이터 구조 유지.

## 배포

기능 브랜치 `feature/global-shortcut-menus-20261106`, main 병합 금지(별도 승인).
최신 커밋의 GitHub Actions Python/Android/Windows PowerShell 전체 회귀 성공 시에만 배포.
Android APK 변경이 있으므로 `-InstallAndroid`를 사용하며, 기존 설치 데이터 삭제 없이 검증한다.
프로그램 배포 후 Core 로컬 `.deploy-info.json`에는 non-secret commit SHA/branch/time/Android 업데이트 여부만 원자적으로 기록한다.
